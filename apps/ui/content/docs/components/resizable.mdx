## Usage

```tsx
import {
  ResizableHandle,
  ResizablePanel,
  ResizablePanelGroup,
} from "@/components/ui/resizable"
```

```tsx
<ResizablePanelGroup>
  <ResizablePanel defaultSize="30">One</ResizablePanel>
  <ResizableHandle />
  <ResizablePanel defaultSize="70">Two</ResizablePanel>
</ResizablePanelGroup>
```

## API Reference

### ResizablePanelGroup

Container for panels and handles. Styled wrapper for `Group` from react-resizable-panels.

| Prop          | Type                        | Default       | Description                                |
| ------------- | --------------------------- | ------------- | ------------------------------------------ |
| `orientation` | `"horizontal" \| "vertical"` | `"horizontal"` | Axis the panels split along.             |

Plus every `Group` prop: `defaultLayout`, `onLayoutChange`, `disableCursor`, `disabled`, `id`, … See the [react-resizable-panels docs](https://github.com/bvaughn/react-resizable-panels).

### ResizablePanel

A single resizable region. Styled wrapper for `Panel`. Sizes are percentage strings (`defaultSize="50"`) or pixel numbers (`defaultSize={200}`); supports `minSize`, `maxSize`, `collapsible`, `onResize`, …

| Prop            | Type       | Default | Description                                                               |
| --------------- | ---------- | ------- | ------------------------------------------------------------------------- |
| `snapPoints`    | `number[]` | —       | Sizes (percentages of the group) the panel snaps to. Requires an `id`.     |
| `snapThreshold` | `number`   | `5`     | Distance in percentage points within which a snap point attracts the panel. |

When a resize gesture settles (drag release or a keyboard resize) inside a snap point's threshold, the panel snaps to that point; the snap delta is absorbed by the largest other panel. Moving away from a snapped point never traps you — the panel only snaps when it *enters* a zone, so a keyboard nudge off a point escapes it. A double-click on the handle still resets the layout to the `defaultSize` values.

### ResizableHandle

The drag handle between panels. Styled wrapper for `Separator`.

| Prop         | Type      | Default | Description                                 |
| ------------ | --------- | ------- | ------------------------------------------- |
| `withHandle` | `boolean` | `false` | Renders a visible grip on the handle.       |
