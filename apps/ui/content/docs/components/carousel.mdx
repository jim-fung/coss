## Usage

```tsx

  Carousel,
  CarouselContent,
  CarouselItem,
  CarouselNext,
  CarouselPrevious,
} from "@/components/ui/carousel"
```

```tsx
<Carousel>
  <CarouselContent>
    <CarouselItem>…</CarouselItem>
    <CarouselItem>…</CarouselItem>
    <CarouselItem>…</CarouselItem>
  </CarouselContent>
  <CarouselPrevious />
  <CarouselNext />
</Carousel>
```

## API Reference

### Carousel

Root component. Wraps Embla Carousel; keyboard and state are provided to children via context.

| Prop          | Type                       | Default       | Description                                        |
| ------------- | -------------------------- | ------------- | -------------------------------------------------- |
| `opts`        | `EmblaOptions`             | —             | Options passed to `useEmblaCarousel`.              |
| `plugins`     | `EmblaPlugin[]`            | —             | Embla plugins.                                     |
| `orientation` | `"horizontal" \| "vertical"` | `"horizontal"` | Slide axis.                                      |
| `setApi`      | `(api: CarouselApi) => void` | —           | Receives the Embla instance for programmatic control. |

### CarouselContent

The scrolling track. Apply `basis-*` classes to items to control how many slides are visible.

### CarouselItem

One slide. `aria-roledescription="slide"` for screen readers.

### CarouselPrevious / CarouselNext

Arrow buttons; reuse the Button `outline` variant, disable at the ends, and rotate for vertical carousels. Accept all [Button](/ui/docs/components/button) props.
