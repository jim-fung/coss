## API Reference

### Rating

Root component. Styled wrapper for the `RadioGroup` from Base UI (via the coss `radio-group` component) that auto-renders `count` stars, previews the rating on hover, and can clear on click.

| Prop            | Type                                        | Default     | Description                                                                                  |
| --------------- | ------------------------------------------- | ----------- | -------------------------------------------------------------------------------------------- |
| `value`         | `number`                                    | -           | The controlled rating value. `undefined` means nothing is rated                              |
| `defaultValue`  | `number`                                    | -           | Initial value for uncontrolled usage                                                         |
| `onValueChange` | `(value: number \| undefined) => void`      | -           | Called with the new rating, or `undefined` when cleared via `allowClear`                      |
| `count`         | `number`                                    | `5`         | Number of stars rendered when no children are passed                                          |
| `allowClear`    | `boolean`                                   | `false`     | Clicking the selected star (or pressing Space on it while focused) clears the rating to `undefined` |
| `size`          | `"sm" \| "default" \| "lg"`                 | `"default"` | Sets `data-size` on the group, which controls the star size                                   |
| `children`      | `React.ReactNode`                           | -           | Replaces the auto-rendered stars with explicit `RatingItem` elements                          |

Note: All other `RadioGroup` props pass through. `disabled` and `readOnly` suppress interaction and the hover preview, `name`, `form`, and `required` wire the group's hidden input into forms, and keyboard navigation (arrow keys, `Home`, `End`) comes from Base UI's radio group.

### RatingItem

One star. Styled wrapper for the `Radio` from Base UI with a `StarIcon` that fills when active.

| Prop         | Type     | Default               | Description                                                        |
| ------------ | -------- | --------------------- | ------------------------------------------------------------------ |
| `value`      | `number` | -                     | The rating value this star represents                              |
| `aria-label` | `string` | `` `${value} stars` `` | Accessible label for the star, singular for `1` (e.g. `3 stars`)   |

Note: All other `Radio` props pass through.

## Notes

- Rating renders a Base UI radio group, so each star is a real radio: arrow keys, `Home`, and `End` move focus and selection, and the group is form-submittable through its hidden input.
- Hovering a star previews the rating by filling stars up to it. The preview is suppressed when `disabled` or `readOnly` is set.
- With `allowClear`, clicking the selected star — or pressing Space on it while focused — clears the rating, and `onValueChange` receives `undefined`.
- Half-star precision is not supported; values are whole numbers from `1` to `count`.
- Pass explicit `RatingItem` children to replace the default `StarIcon` with custom icons per value.
