## Usage

```tsx
import { SelectNative } from "@/components/ui/select-native"
```

```tsx
<SelectNative aria-label="Framework">
  <option value="">Select framework</option>
  <option value="next">Next.js</option>
  <option value="vite">Vite</option>
</SelectNative>
```

## Notes

- Accepts the same `size` variants as the Select trigger: `sm`, `default`, and `lg`.
- Multiple selection is supported via the native `multiple` attribute; the chevron indicator is hidden in that mode.
- Because it renders a real `<select>`, it works without JavaScript and inside server components.
