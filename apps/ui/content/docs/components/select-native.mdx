
## API Reference

### SelectNative

A styled native `<select>`. Server-renderable and functional without JavaScript.

| Prop   | Type                                | Default    | Description                                     |
| ------ | ----------------------------------- | ---------- | ----------------------------------------------- |
| `size` | `"sm" \| "default" \| "lg"`          | `"default"` | Matches the Select trigger sizes.               |

Accepts every native `<select>` prop (`multiple`, `required`, `disabled`, `aria-invalid`, …). With `multiple`, the chevron is hidden and options get accent highlighting.

## Examples

### Multiple and small

`multiple` renders a list box with checked-option highlighting; `size="sm"` matches small form controls.
