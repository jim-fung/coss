## Usage

```tsx
import {
  Stepper,
  StepperIndicator,
  StepperItem,
  StepperSeparator,
  StepperTitle,
  StepperTrigger,
} from "@/components/ui/stepper"
```

```tsx
const [activeStep, setActiveStep] = useState(1)

<Stepper onValueChange={setActiveStep} value={activeStep}>
  {steps.map((step, index) => (
    <StepperItem completed={activeStep > index} key={step} step={index}>
      <StepperTrigger>
        <StepperIndicator />
        <StepperTitle>{step}</StepperTitle>
      </StepperTrigger>
      {index < steps.length - 1 && <StepperSeparator />}
    </StepperItem>
  ))}
</Stepper>
```

## API Reference

### Stepper

Root component. Owns the active-step state and orientation, provided to items via context.

| Prop           | Type                                | Default      | Description                                    |
| -------------- | ----------------------------------- | ------------ | ---------------------------------------------- |
| `value`        | `number`                            | —            | Controlled active step.                        |
| `defaultValue` | `number`                            | `0`          | Uncontrolled initial step.                     |
| `onValueChange`| `(value: number) => void`           | —            | Called when the active step changes.           |
| `orientation`  | `"horizontal" \| "vertical"`        | `"horizontal"` | Layout direction for steps and separators.   |

### StepperItem

One step. Derives `data-state` (`active` / `completed` / `inactive`) from its `step` versus the stepper value.

| Prop       | Type      | Default | Description                                         |
| ---------- | --------- | ------- | --------------------------------------------------- |
| `step`     | `number`  | —       | Zero-based index of this step (rendered as the label). |
| `completed`| `boolean` | `false` | Forces the completed state regardless of `value`.   |
| `disabled` | `boolean` | `false` | Makes the step trigger non-interactive.             |
| `loading`  | `boolean` | `false` | Shows a spinner on the active step.                 |

### StepperTrigger

Clickable trigger around the indicator and title; supports `render`.

### StepperIndicator

Number/check/spinner circle. Supports `render` — the default content flows into custom elements.

### StepperTitle / StepperDescription

Text parts for the step label and optional description.

### StepperSeparator

Connector between steps. Horizontal items distribute with `flex-1`, so separators get real width; turns `bg-primary` when the step is completed.
