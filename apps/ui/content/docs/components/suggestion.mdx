## Usage

```tsx
import { Suggestion, Suggestions } from "@/components/ui/suggestion"
```

```tsx
<Suggestions>
  <Suggestion
    onClick={(suggestion) => console.log(suggestion)}
    suggestion="Explain this code"
  />
</Suggestions>
```

## API Reference

### Suggestions

Wrapping flex row of chips.

### Suggestion

Pill `Button` (`variant="outline" size="xs"`, rounded-full).

| Prop | Type | Description |
| --- | --- | --- |
| `suggestion` | `string` | Prompt text; default children. |
| `onClick` | `(suggestion: string, event: MouseEvent<HTMLButtonElement>) => void` | Called with the suggestion text. |
