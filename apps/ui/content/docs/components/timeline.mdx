## Usage

```tsx
import {
  Timeline,
  TimelineContent,
  TimelineDate,
  TimelineHeader,
  TimelineIndicator,
  TimelineItem,
  TimelineSeparator,
  TimelineTitle,
} from "@/components/ui/timeline"
```

```tsx
<Timeline defaultValue={3}>
  <TimelineItem step={1}>
    <TimelineHeader>
      <TimelineDate>Aug 24, 2026</TimelineDate>
      <TimelineTitle>Order placed</TimelineTitle>
    </TimelineHeader>
    <TimelineIndicator />
    <TimelineSeparator />
    <TimelineContent>Order confirmed and payment processed.</TimelineContent>
  </TimelineItem>
</Timeline>
```

## Notes

- Items with a `step` less than or equal to the Timeline's `value` are marked completed, which fills their indicator and connector.
- Set `orientation="horizontal"` on the `Timeline` for a horizontal layout.
