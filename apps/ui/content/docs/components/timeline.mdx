## Usage

```tsx
import {
  Timeline,
  TimelineContent,
  TimelineDate,
  TimelineHeader,
  TimelineIndicator,
  TimelineItem,
  TimelineSeparator,
  TimelineTitle,
} from "@/components/ui/timeline"
```

```tsx
<Timeline defaultValue={3}>
  <TimelineItem step={1}>
    <TimelineHeader>
      <TimelineDate>Aug 24, 2026</TimelineDate>
      <TimelineTitle>Order placed</TimelineTitle>
    </TimelineHeader>
    <TimelineIndicator />
    <TimelineSeparator />
    <TimelineContent>Order confirmed and payment processed.</TimelineContent>
  </TimelineItem>
</Timeline>
```

## API Reference

### Timeline

Root component. Owns the active-step state used to mark items completed.

| Prop           | Type                                | Default     | Description                                  |
| -------------- | ----------------------------------- | ----------- | -------------------------------------------- |
| `value`        | `number`                            | —           | Controlled number of completed steps.        |
| `defaultValue` | `number`                            | `1`         | Uncontrolled initial value.                  |
| `onValueChange`| `(value: number) => void`           | —           | Called when the value changes.               |
| `orientation`  | `"horizontal" \| "vertical"`        | `"vertical"` | Layout direction.                           |

### TimelineItem

One event. `data-completed` is set when `step <= value`, which fills its indicator and connector.

| Prop   | Type     | Description                                  |
| ------ | -------- | -------------------------------------------- |
| `step` | `number` | 1-based position used against the timeline value. |

### TimelineHeader

Groups the date and title.

### TimelineDate

Timestamp element; supports `render` for custom elements.

### TimelineTitle / TimelineContent

Heading and body for the event.

### TimelineIndicator

The dot on the line; filled via `data-completed` on the item.

### TimelineSeparator

The connector between events; hidden on the last item.
