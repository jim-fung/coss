## Usage

```tsx
import {
  Source,
  Sources,
  SourcesPanel,
  SourcesTrigger,
} from "@/components/ui/sources"
```

```tsx
<Sources>
  <SourcesTrigger count={2} />
  <SourcesPanel>
    <Source href="https://example.com" title="Example reference" />
  </SourcesPanel>
</Sources>
```

## API Reference

### Sources

Collapsible root wrapping the trigger and panel.

### SourcesTrigger

Trigger that defaults to "Used N sources" (singular-aware). Accepts trigger props; `children` replaces the label.

| Prop | Type | Description |
| --- | --- | --- |
| `count` | `number` | Number of cited sources (required). |

### SourcesPanel

Collapsible panel; lay out `Source` items inside.

### Source

External link with a leading icon: renders an anchor with `target="_blank"` and `rel="noreferrer"`, and supports `render` for custom elements (e.g. a router link). Accepts anchor props.

| Prop | Type | Description |
| --- | --- | --- |
| `title` | `string` | Link title; also the label when there are no `children`. |
