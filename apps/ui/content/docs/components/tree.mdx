## Usage

The `Tree` is a styled layer over [Headless Tree](https://headless-tree.lukasbach.com/). Build a tree with `useTree`, then render its items.

```tsx
import { selectionFeature, syncDataLoaderFeature, hotkeysCoreFeature } from "@headless-tree/core"
import { useTree } from "@headless-tree/react"
import { Tree, TreeItem, TreeItemLabel } from "@/components/ui/tree"
```

```tsx
const tree = useTree({
  dataLoader: {
    getChildren: (itemId) => items[itemId]?.children ?? [],
    getItem: (itemId) => items[itemId],
  },
  features: [syncDataLoaderFeature, selectionFeature, hotkeysCoreFeature],
  getItemName: (item) => item.getItemData()?.name,
  isItemFolder: (item) => Boolean(item.getItemData()?.children),
  rootItemId: "root",
})

<Tree indent={20} tree={tree}>
  {tree.getItems().map((item) => (
    <TreeItem item={item} key={item.getId()}>
      <TreeItemLabel>{item.getItemName()}</TreeItemLabel>
    </TreeItem>
  ))}
</Tree>
```

## Notes

- `TreeItemLabel` renders the folder chevron automatically and rotates it based on expansion state.
- Add `dragAndDropFeature` / `keyboardDragAndDropFeature` from Headless Tree and render `TreeDragLine` for drag and drop.
- Selection styles are driven by `data-selected` on items; focus styles by `data-focus`.
