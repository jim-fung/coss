## Usage

The `Tree` is a styled layer over [Headless Tree](https://headless-tree.lukasbach.com/). Build a tree with `useTree`, then render its items.

```tsx
import { selectionFeature, syncDataLoaderFeature, hotkeysCoreFeature } from "@headless-tree/core"
import { useTree } from "@headless-tree/react"
import { Tree, TreeItem, TreeItemLabel } from "@/components/ui/tree"
```

```tsx
const tree = useTree({
  dataLoader: {
    getChildren: (itemId) => items[itemId]?.children ?? [],
    getItem: (itemId) => items[itemId],
  },
  features: [syncDataLoaderFeature, selectionFeature, hotkeysCoreFeature],
  getItemName: (item) => item.getItemData()?.name,
  isItemFolder: (item) => Boolean(item.getItemData()?.children),
  rootItemId: "root",
})

<Tree indent={20} tree={tree}>
  {tree.getItems().map((item) => (
    <TreeItem item={item} key={item.getId()}>
      <TreeItemLabel>{item.getItemName()}</TreeItemLabel>
    </TreeItem>
  ))}
</Tree>
```

## API Reference

### Tree

Root container. Registers the Headless Tree instance (so keyboard handling and focus work) and provides the indent used for nesting.

| Prop     | Type                | Default | Description                                        |
| -------- | ------------------- | ------- | -------------------------------------------------- |
| `tree`   | `TreeInstance<T>`   | —       | Instance from `useTree`.                           |
| `indent` | `number`            | `20`    | Pixels of indentation per nesting level.           |

### TreeItem

One row. Merges Headless Tree's item props (focus, expansion, selection) and supports `render` for custom row elements. Emits `data-focus`, `data-selected`, `data-folder`, `data-drag-target`, and `data-search-match` for styling.

| Prop   | Type                 | Description                          |
| ------ | -------------------- | ------------------------------------ |
| `item` | `ItemInstance<T>`    | Item instance from the tree.         |
| `render` | `ReactElement`     | Replace the rendered row element.    |

### TreeItemLabel

Label with the rotating folder chevron. Accepts an optional `item`, otherwise reads the wrapping item from context.

### TreeDragLine

Drop indicator for drag and drop; reads its position from the tree instance.
