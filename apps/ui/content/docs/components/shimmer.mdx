## Usage

```tsx
import { Shimmer } from "@/components/ui/shimmer"
```

```tsx
<Shimmer>Generating response…</Shimmer>
```

The animation runs through the Web Animations API — no global CSS keyframes needed — and is skipped entirely under `prefers-reduced-motion: reduce`.

## API Reference

### Shimmer

Inline `span` with a muted-to-foreground moving gradient.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `duration` | `number` | `2` | Seconds per shimmer cycle. |
