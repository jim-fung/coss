## Usage

The `Menubar` composes with the [Menu](/docs/components/menu) parts — every menu inside the bar is a regular `Menu` with a `MenubarTrigger`.

```tsx
import {
  Menu,
  MenuItem,
  MenuPopup,
  MenuSeparator,
  MenuShortcut,
} from "@/components/ui/menu"
import { Menubar, MenubarTrigger } from "@/components/ui/menubar"
```

```tsx
<Menubar>
  <Menu>
    <MenubarTrigger>File</MenubarTrigger>
    <MenuPopup align="start">
      <MenuItem>New Tab</MenuItem>
      <MenuItem>
        Open
        <MenuShortcut>⌘O</MenuShortcut>
      </MenuItem>
      <MenuSeparator />
      <MenuItem variant="destructive">Close Window</MenuItem>
    </MenuPopup>
  </Menu>
</Menubar>
```

## Notes

- `MenubarTrigger` replaces `MenuTrigger` inside a menubar so it inherits the bar's styling and `data-popup-open` state.
- Submenus, checkbox items, radio items, and shortcuts work exactly as they do in the Menu component.
