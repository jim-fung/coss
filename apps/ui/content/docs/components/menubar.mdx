## Usage

The `Menubar` composes with the [Menu](/docs/components/menu) parts — every menu inside the bar is a regular `Menu` with a `MenubarTrigger`.

```tsx
import {
  Menu,
  MenuItem,
  MenuPopup,
  MenuSeparator,
  MenuShortcut,
} from "@/components/ui/menu"
import { Menubar, MenubarTrigger } from "@/components/ui/menubar"
```

```tsx
<Menubar>
  <Menu>
    <MenubarTrigger>File</MenubarTrigger>
    <MenuPopup align="start">
      <MenuItem>New Tab</MenuItem>
      <MenuItem>
        Open
        <MenuShortcut>⌘O</MenuShortcut>
      </MenuItem>
      <MenuSeparator />
      <MenuItem variant="destructive">Close Window</MenuItem>
    </MenuPopup>
  </Menu>
</Menubar>
```

## API Reference

### Menubar

Root component. Styled wrapper for `Menubar` from Base UI — provides the container context that coordinates the menus inside it.

| Prop         | Type                       | Default      | Description                                            |
| ------------ | -------------------------- | ------------ | ------------------------------------------------------ |
| `orientation`| `"horizontal" \| "vertical"` | `"horizontal"` | Orientation of the bar.                              |
| `modal`      | `boolean`                  | `true`       | Whether open menus are modal.                          |
| `disabled`   | `boolean`                  | `false`      | Disables every menu in the bar.                        |
| `loopFocus`  | `boolean`                  | `true`       | Wraps arrow-key focus back to the first menu.          |

### MenubarTrigger

Menu trigger styled for the bar. Styled wrapper for `Menu.Trigger` from Base UI; replaces `MenuTrigger` inside a `Menubar` so it inherits the bar's compact styling and `data-popup-open` state.

Every other [Menu](/ui/docs/components/menu) part (`MenuPopup`, `MenuItem`, `MenuSub`, `MenuCheckboxItem`, …) works inside the bar unchanged.
