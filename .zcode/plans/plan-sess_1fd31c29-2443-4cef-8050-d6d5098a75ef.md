# AI Chat Suite for coss — 8 registry components, fork-main only (no upstream PR)

Reference: Vercel AI Elements (Apache-2.0) API shapes, re-skinned to coss conventions with **zero `ai`-package coupling** (our own role/status unions). One new dep: `use-stick-to-bottom`. Work lands directly on fork `main` and pushes to `origin` (jim-fung/coss). No upstream branch, no split-artifact cherry-pick dance.

## Components (author in `apps/ui/registry/default/ui/`, then sync)

1. **`shimmer.tsx`** — animated gradient text via Web Animations API (self-contained, no globals.css keyframes; respects `prefers-reduced-motion`). Used by reasoning trigger; standalone too.
2. **`conversation.tsx`** — `Conversation` (use-stick-to-bottom wrapper, `role="log"`, aria-live), `ConversationContent`, `ConversationEmptyState` (composes `@coss/empty`), `ConversationScrollButton` (visible only when `!isAtBottom`), `ConversationDownload` + `messagesToMarkdown` (generic `{role, content}[]`, `formatMessage` override).
3. **`message.tsx`** — `Message` (role prop `user | assistant | system | tool`, `data-from` attr, user bubble right-aligned), `MessageContent`, `MessageActions`/`MessageAction` (tooltip + sr-only label, ghost icon-sm default), branch family `MessageBranch`/`MessageBranchSelector`/`MessageBranchPrevious`/`MessageBranchNext`/`MessageBranchPage` (controlled/uncontrolled index + context), `MessageToolbar`.
4. **`prompt-input.tsx`** — form composer composing `@coss/input-group` + `@coss/button` + `@coss/tooltip` + `@coss/select`: `PromptInput` (`onSubmit({text, files?}, e)`, reset-on-submit), `PromptInputTextarea` (auto-grow; Enter submits, Shift+Enter newline), `PromptInputHeader`/`Footer`/`Tools`, `PromptInputButton` (tooltip prop), `PromptInputSubmit` (`status: "ready" | "submitted" | "streaming" | "error"` icon swap), `PromptInputSelect` pass-throughs. No attachment file management (pairs with future file-upload).
5. **`reasoning.tsx`** — collapsible-based: `Reasoning` (internal duration clock from `isStreaming` transitions; auto-open on stream start unless `defaultOpen === false` explicitly; auto-close 1s after end, once), `ReasoningTrigger` (pulsing indicator + Shimmer "Thinking…" → "Thought for Ns"), `ReasoningPanel` (coss house naming: collapsible regions are `*Panel`, not `*Content`).
6. **`sources.tsx`** — `Sources`, `SourcesTrigger` (count → "Used N sources"), `SourcesPanel`, `Source` (safe external anchor).
7. **`tool.tsx`** — `Tool`, `ToolHeader` (state badge over union `input-streaming | input-available | approval-requested | approval-responded | output-available | output-error | output-denied`), `ToolPanel`, `ToolInput` (pretty-printed JSON), `ToolOutput`.
8. **`suggestion.tsx`** — `Suggestions` (flex-wrap) + `Suggestion` (chip button, onClick/vrom prompt).

All parts: `data-slot` everywhere, explicit `: React.ReactElement` returns, `useRender` on swappable parts, context+private hook for stateful compounds (message-branch, reasoning), semantic tokens only, `aria-hidden` icons + `aria-label` icon-only buttons.
